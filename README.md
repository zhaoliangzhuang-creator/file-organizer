# file-organizer
基于 Python 和 Tkinter 的文件分类整理工具，支持预览、同名处理和图形界面。

# 文件整理助手

基于 Python 和 Tkinter 的桌面文件整理工具。

## 功能

- 支持图片、文档、表格、演示、音频、视频、压缩包等 12 类文件
- 整理前预览源文件、目标路径和处理状态
- 同名文件可以跳过或自动重命名
- 未知类型可选择归入 others
- 执行前检查文件是否在预览后发生变化
- 后台处理文件，界面显示进度和逐项结果

## 运行环境

- Python 3.12 或更高版本
- tkinter
- 当前在 Windows、Python 3.13 环境中测试

程序只使用 Python 标准库，无需安装第三方 Python 包。

## 使用方法

下载项目并解压，在项目目录打开终端，运行：

```bash
python gui_v2.py
```

操作步骤：

1. 选择需要整理的文件夹。
2. 设置同名文件处理方式。
3. 点击“预览整理”，检查目标路径。
4. 点击“开始整理”。

## 项目结构

- gui_v2.py：图形界面、后台任务和结果显示
- test1.py：分类规则、整理计划和文件操作
- test_organizer.py：自动测试

## 运行测试

```bash
python -m unittest -v test_organizer
```

## 当前限制

- 只整理所选文件夹的第一层，不递归处理子文件夹
- 根据扩展名分类，不识别文件内容
- 暂不支持一键撤销
- 复制成功后删除源文件，大文件处理需要额外磁盘空间
